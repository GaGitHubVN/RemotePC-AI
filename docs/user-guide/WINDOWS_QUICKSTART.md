# RemotePC AI for Windows — Quick start

1. Run RemotePC-AI.exe (no installation, no administrator rights). It creates a `data` folder next to itself.
2. Click **Pair a phone** and scan the QR code with the RemotePC AI app on your iPhone/Android.
3. Compare the 6-digit code on both screens, choose permissions, click **Allow**.
4. A banner at the top of the screen is shown whenever someone is connected. **Disconnect all** ends every session.

Full documentation: README.md in the source repository.
